# 🚂 CRTicketMonitor 12306 余票查询与监控助手

[![Python Version](https://img.shields.io/badge/python-3.14+-blue.svg)](https://www.python.org/) [![License](https://img.shields.io/badge/license-MIT-green.svg)](https://opensource.org/licenses/MIT) [![Version](https://img.shields.io/badge/version-3.2.0-orange.svg)](https://github.com/)

这是一个轻量级的 12306 余票查询与监控工具，使用 AI 辅助进行开发。该工具目前尚在完善之中，作者代码水平不高，学习的时间较长，遇到问题还请多多见谅！

---

## 一、核心功能

### （一）GUI 界面功能

* **可视化界面**：基于 PySide6 的现代化 GUI 界面，操作直观便捷；
* **窗口自适应**：自动适配用户屏幕大小，居中显示；
* **高级筛选面板**（v3.1+）：模仿 12306 网站样式，提供实时筛选功能
  - **车次类型筛选**：高铁/城际 - G/C、动车 - D、直达 - Z、特快 - T、快速 - K、其他、复兴号、智能动车组
  - **出发站筛选**：支持多选，带搜索功能，根据输入城市名智能过滤同城市车站
  - **到达站筛选**：支持多选，带搜索功能，根据输入城市名智能过滤同城市车站
  - **席别筛选**：商务座、一等座、二等座、软卧、硬卧、无座
  - **发车时段筛选**：00:00-24:00、00:00-06:00、06:00-12:00、12:00-18:00、18:00-24:00
* **车次标识**：复兴号车次显示"复"字，智能动车组显示"智"字（小字标识）
* **车站选择器**：独立的出发站/到达站选择按钮，点击弹窗选择，智能显示同城市车站
* **重置功能**：一键重置所有查询条件和筛选条件
* **表格排序**：点击"开点"、"到点"、"历时"列头可升降序排序（最早/最晚发车、最早/最晚到达、最长/最短历时）
* **收藏功能**：收藏的车次显示黄底，有票车次显示绿底，右键菜单可取消收藏
* **监控模式**：自动/手动两种监控模式，可配置刷新间隔
* **通知提醒**：发现目标车次有票时发送桌面通知
* **快捷操作**：查询条件栏集成"打开 12306"按钮，无查询时打开首页，有查询时打开预填好信息的页面

### （二）命令行功能

* **席位覆盖**：支持商务座、一等座、二等座、软座、卧铺等常用席位查询；
* **车站同步**：自动从 12306 官方实时抓取最新的车站代码映射表；
* **异常自动纠错**：查询时若输入了本地未记录的车站，程序会自动触发二次同步，确保查询成功；
* **双模式监控**：
  - **自动模式 (Auto)**：自定义随机间隔刷新，适合长时间挂机监控；
  - **手动模式 (Manual)**：按需手动刷新，灵活掌握查询节奏；
* **高亮视觉提醒**：查询到有票的车次时，车次编号将以**绿色**显著标出；
* **及时通知**：当发现有票的车次时将进行筛选，在下一次刷新时进行对比，实现**强提醒**（该功能部分杀毒软件可能会提示，选择允许即可）

## 二、快速开始

### （一）环境准备

在运行此程序之前，你需要安装以下依赖库：

1. **PySide6**: Qt6 图形界面库
2. **Requests**: 用于处理网络请求
3. **PrettyTable**: 用于在终端输出表格
4. **Pillow**: 图像处理库
5. **PyInstaller**: 打包工具

你可以通过 `requirements.txt` 一键安装：

```bash
pip install -r requirements.txt
```

### （二）运行程序

**GUI 模式（推荐）**：

```bash
python main.py
```

**命令行模式**：

```bash
python cli_entry.py
```

### （三）打包为可执行文件

```bash
pyinstaller --clean CRTicketMonitor.spec
```

编译完成后，EXE 文件位于 `dist/CRTicketMonitor.exe` 目录下。

## 三、GUI 界面操作指南

### （一）主界面布局

启动程序后，显示 GUI 主界面，主要包含以下区域：

1. **查询条件区**：出发站、到达站、日期输入框，以及"选择"车站按钮和"打开 12306"按钮
2. **功能按钮区**：查询、开始监控、停止监控、收藏选中车次等按钮
3. **筛选面板**：车次类型、车站、席别、时段筛选
4. **结果表格区**：显示车次信息和余票数据

### （二）查询操作

1. **输入查询条件**：
   - 在出发站、到达站输入框输入车站名称（支持拼音首字母）
   - 点击旁边的"选择"按钮可弹出车站选择器
   - 车站选择器会根据已输入的城市名，智能显示同城市的车站（如输入"长沙"时显示"长沙、长沙南、长沙西"）
   - 选择出发日期

2. **执行查询**：
   - 点击"查询"按钮获取余票信息
   - 查询结果以表格形式展示

3. **打开 12306**：
   - 无查询结果时：打开 12306 首页
   - 有查询结果时：打开预填好出发站、到达站、日期的页面

### （三）筛选功能

所有筛选条件支持**实时生效**，勾选复选框或更改下拉菜单后立即刷新表格显示。

#### 1. 车次类型筛选

- **高铁/城际 - G/C**：高铁和城际列车
- **动车 - D**：动车组列车
- **直达 - Z**：直达特快列车
- **特快 - T**：特快列车
- **快速 - K**：快速列车
- **其他**：未分类车次
- **复兴号**：仅显示复兴号车次（带"复"字标识）
- **智能动车组**：仅显示智能动车组（带"智"字标识）

#### 2. 出发站/到达站筛选

- 支持多选
- 可在搜索框输入车站名或拼音首字母快速定位
- 勾选需要的车站，表格自动过滤

#### 3. 席别筛选

- 商务座、一等座、二等座、软卧、硬卧、无座
- 勾选后仅显示有对应席别的车次

#### 4. 发车时段筛选

下拉菜单选择：
- **00:00-24:00**：全部时段
- **00:00-06:00**：凌晨时段
- **06:00-12:00**：上午时段
- **12:00-18:00**：下午时段
- **18:00-24:00**：晚间时段

### （四）重置筛选

点击"重置查询与筛选"按钮，将所有筛选条件恢复到默认状态（全部选中）。

### （五）表格操作

- **排序**：
  - 点击"开点"列头：最早发车 ⇄ 最晚发车
  - 点击"到点"列头：最早到达 ⇄ 最晚到达
  - 点击"历时"列头：最短历时 ⇄ 最长历时
- **收藏**：右键点击车次，选择"收藏此车次"，该车次显示黄底；有票车次显示绿底
- **取消收藏**：右键点击已收藏车次，选择"取消收藏"
- **双击**：双击车次可收藏/取消收藏该车次

### （六）监控功能

1. 点击"开始监控"按钮，进入监控模式
2. 可选择监控模式：
   - **自动模式**：按设定的随机间隔自动刷新
   - **手动模式**：按需手动刷新
3. 发现目标车次有票时发送桌面通知

## 四、命令行版本操作指南

### （一）一级菜单 (启动后)

```
启动主菜单
-----------------------------------------------------------------
1. 开始新的查询
2. 修改默认配置
3. 查看查询历史
4. 通知设置
5. 退出程序
-----------------------------------------------------------------
```

**操作说明**:
- `1`: 进入 12306 余票查询界面
- `2`: 修改 DC 识别模式、通知冷却时间等配置
- `3`: 查看历史查询记录和统计信息
- `4`: 配置通知渠道（Windows/企业微信/飞书/钉钉）
- `5`: 退出程序

### （二）查询界面操作

进入查询后，显示车次列表，底部有操作提示：

```
[F] 筛选排序  [M] 切换模式  [E] 导出结果  [R] 重新查询  [Q] 退出
```

**操作说明**:
- `F`: 按 `F` 键进入二级筛选/排序菜单
- `M`: 切换 D/C 低号段的识别模式（官方模式/智能模式）
- `E`: 导出查询结果到 JSON 文件
- `R`: 重新开始查询
- `Q`: 退出程序
- `Enter`: 立即刷新一次

### （三）二级筛选/排序菜单

按 `F` 键进入后，显示如下菜单：

```
筛选与排序菜单
================================================================
[当前筛选]
  车型：全部 | 始发：全部 | 到达：全部
  时段：全部时段 | 排序：无
----------------------------------------------------------------
[车型筛选]  1.全部  2.高铁动车  3.普通车
[站点筛选]  4.始发站  5.到达站
[时段筛选]  6.全部时段  7.00:00-06:00  8.06:00-12:00  9.12:00-18:00  0.18:00-24:00
[排序选项]  A.最早发车  B.最晚发车  C.最早到达  D.最晚到达  E.最短历时  F.最长历时
[其他]      R.重置筛选  X.返回主查询
----------------------------------------------------------------
```

##### 1. 车型筛选 (选项 1-3)
- `1`: 显示全部车型
- `2`: 仅显示高铁动车
- `3`: 仅显示普通车

##### 2. 站点筛选 (选项 4-5)

选择始发站或到达站时，系统会列出**所有可用车站**供选择：

```
【始发站列表】
========================================
 1. 广州   2. 广州白云   3. 广州东  4. 广州新塘
 5. 广州北
...
输入序号选择（按回车跳过）:
```

- 输入车站对应的序号即可选择
- 按回车键跳过，表示"全部"不进行筛选

##### 3. 时段筛选 (选项 6-0)
- `6`: 全部时段
- `7`: 00:00-06:00
- `8`: 06:00-12:00
- `9`: 12:00-18:00
- `0`: 18:00-24:00

对于争议比较大的，06:00 归入 06:00-12:00 时段，12:00 归入 12:00-18:00 时段，18:00 归入 18:00-24:00 时段。此外，这个时段是发车的时段，不是到达时间的时段。

**注意：** 目前已知在识别运行图调整的车次时，到发时间会显示错误的问题。

##### 4. 排序功能 (选项 A-F)
- `A`: 按发车时间升序（最早发车）
- `B`: 按发车时间降序（最晚发车）
- `C`: 按到达时间升序（最早到达）
- `D`: 按到达时间降序（最晚到达）
- `E`: 按历时升序（最短历时）
- `F`: 按历时降序（最长历时）

##### 5. 其他操作
- `R`: 重置所有筛选条件
- `X`: 返回主查询界面

## 六、配置说明

### （一）修改配置 (命令行版本菜单选项 2)

进入配置修改菜单，可以调整以下参数：

1. **切换 DC 识别模式** (当前：official)
   - `official`: D/C 字头全归为高铁动车
   - `smart`: D/C 字头 1-899 归为普通车

2. **修改智能识别阈值** (当前：899)
   - 建议保持默认值

3. **修改通知冷却时间** (当前：300 秒)
   - 避免频繁发送通知

4. **设置仅监控目标车次** (当前：否)
   - 仅对指定车次发送通知

5. **修改最小余票数量** (当前：1)
   - 达到此数量才发送通知

### （二）通知设置 (命令行版本菜单选项 4)

支持多种通知渠道：
- Windows 原生通知
- 企业微信机器人
- 飞书机器人
- 钉钉机器人
